# Введение

С распространением интернета и его превращением во «всемирную сеть» бизнес начал активно использовать его как посредника
в коммуникации с потенциальными клиентами.

Взаимодействие может быть организовано на разных уровнях:

- **Непосредственное представительство.** Бизнес размещает сайт в сети, и всё взаимодействие «клиент–продавец»
  происходит через него. Способ привлечения клиента на сайт не анализируется.
- **Продвижение сайта.** Бизнес взаимодействует с поисковыми системами для максимального повышения видимости сайта в
  ответ на поисковые запросы пользователей. Помимо индексирования контента, современные поисковые системы учитывают
  семантическую близость запроса и документа, включая в выдачу ссылки, не имеющие точного совпадения с запросом, но
  близкие по тематике. Если рассматривать страницы в индексе как «товар», а упоминание темы запроса на странице — как
  «взаимодействие», то подбор близких по теме страниц становится схож с работой рекомендательных алгоритмов.
- **Персонализированный подбор рекомендаций.** Система формирует выдачу, максимально ориентированную на текущие
  предпочтения и потребности конкретного пользователя. Ключевая особенность рекомендательной системы — проактивность:
  она не ждёт явного запроса пользователя, а заранее провоцирует его на совершение целевого действия. Для этого система
  собирает историю всех потенциально значимых действий: какие разделы просматривал, какие детали уточнял (`click_on_author`,
  `open_comments`), как долго смотрел (`timespent`), что одобрил (`like`) или отверг (`dislike`), и
  многое другое. На основе этой информации система прежде всего показывает пользователю тот контент, который с
  наибольшей вероятностью его заинтересует, и только затем — всё остальное. Кроме переупорядочивания выдачи,
  рекомендации могут учитываться при формировании персональных маркетинговых акций для увеличения вероятности целевого
  действия.

**Рекомендательная система** — это информационная система, которая отслеживает действия пользователя, способные помочь
предсказать, какая информация или продукт сейчас наиболее им востребованы. Вся накопленная информация агрегируется в
пользовательский профиль и используется для формирования персонализированной выдачи.

**Алгоритм рекомендательной системы** — это алгоритм, предназначенный для автоматического подбора релевантных текущим
интересам пользователя предложений.

# Постановка задачи

В рамках данного проекта рассматривается задача **персонализированного предсказания следующего выбора пользователя** на
видеохостинге. Формально, для каждого пользователя $u$ по истории его взаимодействий с видеороликами необходимо
сформировать упорядоченный список из $K$ роликов, которые он с наибольшей вероятностью готов просмотреть следующими.

## Формализация

Пусть:

- $\mathcal{U}$ — множество пользователей.
- $\mathcal{I}$ — множество видеороликов.
- $H_u = [i_1, i_2, \ldots, i_t]$ — упорядоченная по времени история взаимодействий пользователя $u \in
  \mathcal{U}$, где $i_k \in \mathcal{I}$ — ролик, просмотренный на шаге $k$.

**Задача:** для каждого пользователя $u$ с историей $H_u$ построить функцию скоринга:

$$
f_u: \mathcal{I} \setminus H_u \rightarrow \mathbb{R}
$$

и вернуть топ-$K$ роликов с наибольшими значениями:

$$
\text{top-}K(u) = \underset{i \in \mathcal{I} \setminus H_u}{\text{argtop-}K} \; f_u(i)
$$

где $\mathcal{I} \setminus H_u$ — множество роликов, с которыми пользователь не взаимодействовал в тренировочном
периоде ($\mathbf{S_{u}}$ включает как позитивные, так и негативные взаимодействия).

## Целевые метрики

Качество рекомендаций оценивается по стандартным для задачи next-item prediction метрикам:

- **Recall@K** — доля верных айтемов из ground truth, попавших в топ-K.
- **HitRate@K** — доля пользователей, у которых хотя бы один верный айтем попал в топ-K.
- **NDCG@K** — нормализованный кумулятивный выигрыш, учитывающий позицию правильного ответа в выдаче.
- **MRR (Mean Reciprocal Rank)** — среднее обратное ранга первого релевантного элемента.

Оценка производится на отложенной тестовой выборке с разделением по времени: для каждого пользователя последние
взаимодействия используются как ground truth, предыдущие — как обучающая история.

## Рассматриваемые подходы

В работе сравниваются четыре класса алгоритмов:

1. **MostPopular** — неперсональный baseline, ранжирующий ролики по глобальной частоте позитивных взаимодействий в
   обучающей выборке.
2. **FPMC (Factorized Personalized Markov Chains)** — комбинация матричной факторизации (персональные предпочтения) и
   марковских переходов первого порядка (контекст последнего просмотра).
3. **SASRec (Self-Attentive Sequential Recommendation)** — sequential-модель на основе self-attention, кодирующая всю
   упорядоченную историю пользователя.
4. **LightGCN (Light Graph Convolutional Networks)** — модель на основе графовых сверток, обучающая персональные
   эмбеддинги пользователей и роликов на позитивных ребрах графа взаимодействий.

## Гибридный ансамбль
Помимо сравнения моделей по отдельности, в работе строится гибридный ансамбль, назначающий каждому пользователю наиболее
подходящую модель на основе размера его истории взаимодействий в тренировочном периоде. Пользователи разделяются на три
группы: холодные, тёплые и горячие. Для каждой группы выбирается модель, показавшая наилучшие метрики на валидационной выборке.

_Примечание: в текущей реализации деплой в prod ни как не рассмотрен, система училась один раз, на ограниченной
подвыборке, и по результатам обучения задано жесткое соответствие группы пользователя модели, которая используется для
получения его прогноза._

## Ограничения и допущения

- В рамках проекта используются как неявные сигналы (длительность просмотра timespent), так и явные реакции
  пользователя (like, dislike, share, bookmark, click_on_author, open_comments). Единая функция разметки агрегирует оба
  типа сигналов: действие считается позитивным при длительном просмотре или наличии любой позитивной реакции;
  негативным — при явном дизлайке или коротком просмотре без позитивных сигналов.
- Все модели обучаются на **одних и тех же временных сплитах** для корректного сравнения.
- Из выдачи исключаются ролики, уже просмотренные пользователем.
